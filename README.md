# ⚡ HanakaMagneticPoints — Магнитные точки

**Версия:** 2.0.0 · **Ядро:** Paper 1.21.11 · **API:** 1.21 · **Java:** 21

Плагин добавляет на сервер **магнитные точки** — места, которые притягивают металлические предметы и игроков с металлом в радиусе действия. Идеально для ванильного выживания: больше не нужно бегать за выпавшим незеритом!

## ✨ Возможности

- 🧲 **Притяжение металлических предметов** — железо, золото, незерит и всё, что из них сделано
- 👤 **Притяжение игроков** — чем больше металла в руках и на броне, тем сильнее тянет
- 🛡 **Защита** — крадущиеся (Shift), игроки на элитрах, в полёте, в креативе и в режиме наблюдателя не притягиваются
- ⚖️ **Весовая физика** — незерит (10) тянется сильнее, чем мелочь (2)
- 📊 **Индикатор силы** в экшн-баре: «Притяжение N ед.» + градиентная полоска
- ✨ **Анимация частиц** по кругу вокруг точки + фоновый звук маяка
- 🖥 **Удобный GUI** — телепорт, вкл/выкл и удаление точек кликами мыши, с пагинацией
- 🌈 **Зелёно-лаймовый градиент** во всех сообщениях (цвета меняются в конфиге)
- 💾 Точки сохраняются при перезапусках сервера (`points.yml` + автосохранение)
- ⚙️ **Всё настраивается** — скорости, защита, частицы, звуки, GUI, веса материалов, все тексты

## 📦 Установка

1. Скачайте `HanakaMagneticPoints-2.0.0.jar` из [Releases](../../releases/latest).
2. Положите файл в папку `plugins/` сервера Paper 1.21+.
3. Перезапустите сервер — появятся `plugins/HanakaMagneticPoints/config.yml`, `messages.yml` и `points.yml`.
4. Настройте файлы под себя и выполните `/magnet reload`.

## 📋 Команды

Алиасы: `/magnet`, `/hanakamagnetic`, `/hanakamagneticpoints`, `/hmagnetic`, `/hmp`, `/magneticpoints`, `/magnetpoints`.

| Команда | Описание |
| --- | --- |
| `/magnet add <название>` | создать точку в месте, где ты стоишь |
| `/magnet remove <название>` | удалить точку |
| `/magnet list` | список всех точек (клик по строке — телепорт) |
| `/magnet info <название>` | мир, координаты, радиус, статус, автор, дата |
| `/magnet toggle <название>` | включить или выключить точку |
| `/magnet tp <название>` | телепорт к точке |
| `/magnet radius <название> <радиус>` | изменить радиус (3–100 блоков) |
| `/magnet gui` | открыть GUI-панель управления |
| `/magnet particles <on/off/admin>` | видимость частиц |
| `/magnet reload` | перезагрузить конфиг и точки |

### 🖱 Горячие клавиши в GUI

- **ЛКМ** — телепорт к точке
- **ПКМ** — вкл/выкл точку
- **Shift + ПКМ** — удалить точку

## 🔒 Права

| Право | По умолчанию | Описание |
| --- | --- | --- |
| `magnet.admin` | OP | доступ ко всем командам `/magnet` |
| `magnet.gui` | OP | доступ к GUI-панели |
| `magnet.particles.see` | OP | видеть частицы в режиме `visibility: admin` |
| `magnet.bypass` | нет | игрока не притягивает ни одна точка |

## ⚙️ Настройка (config.yml)

Основные блоки конфига:

| Секция | Что настраивает |
| --- | --- |
| `settings` | радиусы (`default-radius: 12.0`, `min-radius`, `max-radius`), `strength-multiplier`, частота обновления, лимит точек, отключённые миры, автосохранение |
| `gradient` | цвета градиента: `start: "#00E676"`, `end: "#C6FF00"` и отдельный градиент ошибок |
| `items` | притяжение предметов: скорость, подъём, остановка в центре |
| `players` | притяжение игроков, учёт рук/брони/инвентаря, экшн-бар, защита |
| `particles` | `enabled`, `type: WAX_ON`, `count: 24`, `visibility: admin`, вращение, кольца, дальность показа |
| `sounds` | `ambient: BLOCK_BEACON_AMBIENT`, `volume: 0.3`, `pitch: 1.5`, звуки интерфейса |
| `gui` | размер панели, материалы иконок и кнопок, автообновление |
| `teleport` | смещение по Y и поиск безопасного места |
| `materials` | списки магнитных материалов с весами и масками типа `NETHERITE_*` |

### ⚖️ Веса материалов

| Вес | Материалы |
| --- | --- |
| 10 | незерит: слитки, блоки, древние обломки, всё незеритовое снаряжение |
| 8 | железо и золото: блоки, слитки, магнит, наковальни |
| 6 | железные инструменты, броня, руды |
| 4 | золотые инструменты, двери, люки, решётки, воронки, казаны |
| 2 | кольчуга, мелкие слитки, вёдра, вагонетки, рельсы, часы, громоотвод и другое |

Любой материал можно добавить, убрать или перевесить в секции `materials`, включая маски (`NETHERITE_*`) и список исключений `ignored`.

## 💬 Сообщения (messages.yml)

Все тексты вынесены в `messages.yml` и поддерживают MiniMessage.

- `<g>текст</g>` — зелёно-лаймовый градиент из `gradient.start` → `gradient.end`
- `<e>текст</e>` — градиент ошибки
- поддерживаются любые теги MiniMessage: `<hover>`, `<click>`, `<bold>`, `<gradient:#00E676:#C6FF00>` и др.

## 🔨 Сборка из исходников

Требуется JDK 21 и Maven 3.9+:

```bash
git clone https://github.com/x1no4ekk/HanakaMagneticPoints.git
cd HanakaMagneticPoints
mvn clean package
```

Готовый файл: `target/HanakaMagneticPoints-2.0.0.jar`.

Каждый пуш в `main` собирается автоматически через GitHub Actions, а JAR публикуется в [Releases](../../releases/latest).
